# Security

Gom keeps family chats, so a hole in it matters. If you find one, please tell the owner privately, never in a public issue,
pull request or discussion.

## How to report

Use GitHub's private report: the repository's **Security** tab › **Report a vulnerability**
([direct link](https://github.com/quaint666/gom/security/advisories/new)). Say what you found, how to make it happen, and
what someone could do with it. A short report is fine; Vietnamese or English.

Please do not read, change or keep anyone else's messages or files to prove a point: a test account of your own is enough.

## What happens next

The owner aims to answer within a week, works on a fix in private, and releases it. You are named in the release notes if you
want to be.

## What is covered

The server, the web pages and the Android app in this repository, at their latest release. A copy of Gom that someone else
runs is theirs to fix, from the same code.
